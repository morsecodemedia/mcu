# Ecosystem Values

## Reduce Friction

The ecosystem exists to reduce friction between intention and execution.

---

## Progressive Disclosure

Users should not need to understand every subsystem to be productive.

Complexity should be introduced only when it becomes useful.

---

## Learn by Using

The ecosystem should encourage curiosity.

As users become more capable, the ecosystem should naturally expose deeper concepts.

Understanding should be rewarded, not required.

---

## Independent Capabilities

Every capability should provide value on its own.

The ecosystem should become more powerful when capabilities work together, but no capability should require another unless explicitly declared.

---

## Human First

The ecosystem exists to amplify human capability.

Automation supports engineering judgment.

It does not replace it.
