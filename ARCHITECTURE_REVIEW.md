# Architecture Review

## Vision
- [ ] Every repository supports the vision.
- [ ] Every discipline supports the vision.

## Organization
- [ ] Every repository belongs to exactly one discipline.
- [ ] Every capability has a clear owner.
- [ ] No repository has multiple constitutional responsibilities.

## Governance
- [ ] Authority is clearly defined.
- [ ] Recommendation vs. decision is consistent.
- [ ] CEO authority is preserved.

## Workflow
- [ ] Every workflow has an owner.
- [ ] Every work type maps to a workflow.

## Disciplines
- [ ] Every responsibility has exactly one owner.
- [ ] No responsibility is shared without explicit governance.

## Repositories
- [ ] Every repository has a single mission.
- [ ] Every "Never Owns" section aligns with discipline boundaries.
- [ ] Every dependency is intentional.
